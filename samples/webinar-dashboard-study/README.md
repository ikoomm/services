# Session — independent webinar dashboard study

Original, AI-assisted interface concept by ikoomm. Built as a limited demonstration of a creator dashboard, not commissioned client work or a completed webinar platform. All events, people and metrics are illustrative.

## Design decisions

- Put the next session and its readiness checklist before aggregate metrics.
- Separate registration, attendance and replay counts; explicitly acknowledge overlap.
- Give attendee previews a mobile-friendly layout and an honest disconnected-demo notice.
- Use restrained green, warm surfaces, strong text hierarchy and native controls.

## Working interactions

Session filters, attendee preview dialogs, a four-item checklist, an in-memory draft form, and collapsible mobile navigation. The draft title is rendered as text, never HTML. No backend, video, email, signups, analytics, storage or external assets. Refresh resets edits.

Open index.html in a modern browser or serve this directory locally. No dependencies or build step.

This HTML study is not an editable Figma file. Figma design work in a future paid engagement would be a separate agreed deliverable.
