    Built to be checked

    Raw CSV fixtures → Python validation and aggregation → JSON → this report. Ratios use total numerators and denominators, never an average of row percentages.

    • Two complete seven-day periods; currency and reporting timezone are explicit.
    • Missing metrics fail validation. A zero denominator produces “N/A”, not a made-up rate.
    • Meta-attributed purchases and GA4 purchases stay separate.

    Scope of this demonstration

    This is an original HTML/Python reporting sample using invented data, created 29–30 September 2026. It is not client work, a live API integration, a Looker Studio dashboard or a completed n8n deployment.

    The source package includes input fixtures, calculations and regression tests. Live API permissions, selected metrics and native platform delivery would be verified separately.
