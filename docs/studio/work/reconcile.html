Software · Internal product

The latest export. Without the guesswork.

Export Reconcile is a working browser-local tool, built as an internal product experiment. Its sample data is synthetic. No paying customer or time-saving result has been verified.

The problem

Recurring exports can overwrite newer records or hide conflicting updates. The product addresses a bounded version: two CSVs with matching headers, one exact ID and one dated update rule.

The strategy

Put review before replacement. Process files locally, show changes and issues, and preserve the original inputs. Avoid fuzzy matching or a silent best guess when dates conflict.

What was built

  • A live browser tool and downloadable standalone HTML version.
  • Exact ID/date matching; a newer record replaces the whole row, while tied conflicting records are held for review.
  • Updated master, change log and issue log downloads, with conservative spreadsheet-formula protection.
  • Editable JavaScript source and documented input/edge-case behavior.

Supported: UTF-8 comma-separated CSV, up to 5 MB and 50,000 combined rows. Not Excel workbooks, fuzzy matching or a production data warehouse.

Measurement plan

Observe whether a qualified user completes one import, understands a conflict and can use the exported result. Compare an agreed manual task against the tool with the same files. Track corrections and actual minutes, not speculative hours saved. No external user count is currently verified.

Example onboarding

“Start with the synthetic example. Pick the ID and update date, preview the changes, then inspect Issues before downloading. Your files stay in the tab.” This is onboarding copy written for the product, not a sent client campaign.
