Two separate views. No combined attribution claim.

The problem

The demo brief: make a weekly marketing report understandable and reproducible. Comparing rates incorrectly or adding incompatible attribution totals can make a polished dashboard misleading.

The strategy

Separate Meta and GA4 views. Compare adjacent Monday–Sunday weeks in an explicit currency and timezone. Aggregate numerators and denominators before calculating rates. Produce short, checkable summaries instead of invented causal explanations.

What was built

  • Meta Ads campaign report: spend, impressions, clicks, purchases, revenue and weighted derived metrics.
  • GA4 acquisition report: sessions, engaged sessions, purchase events and attributed revenue by channel.
  • Python/Decimal computation, explicit null reasons, source fixtures, calculated JSON and 13 passing unit tests.
  • Responsive HTML report tabs and three deterministic factual summary lines for each view.

Weeks: 14–20 and 21–27 September 2026. USD; Asia/Kolkata. Purchase events divided by sessions is not GA4 session key-event rate.

Measurement plan

In a funded integration, first reconcile selected totals with approved source reports. Monitor missing pulls, duplicate rows, delivery timing and recipient usefulness. Advertising profit or causal uplift would need separate costs, attribution decisions and a real experiment.

What remains separate

Live permissions, API pagination, late conversions, new/retired dimensions, retries, Sheets updates, n8n scheduling and Looker delivery are not completed by this demo. Desktop/mobile browser inspection of this new report is pending a supported-browser connection repair; calculation tests and published-file checks passed.
