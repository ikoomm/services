Local service · Concept project

A menu with a clearer path.

Mora Table is an independent restaurant concept. The website and video exports exist; no restaurant hired us and no conversion improvement is claimed.

The problem

The concept brief: help a mobile visitor understand the restaurant and browse the menu without hunting through a long page. This is a design problem set for an invented venue, not observed customer research.

The strategy

Make the menu the central action. Keep category navigation, item names, descriptions and sample prices visible. Carry that same path into short video: a hook, the interface in use and one next action.

What was built

  • Responsive restaurant website with mobile menu and category navigation.
  • Two actual 20-second, 1080 × 1920 MP4 exports. The opening four seconds change; the body and CTA remain the same.
  • Editable website source and Python composition; original synthesized audio. No filmed spokesperson or paid music.

Hook A: “Your menu. One clear path.” Hook B: “Less hunting. More browsing.” Neither has been tested with a live audience.

Measurement plan

With a real restaurant and consented analytics, measure menu-entry rate, category engagement and reservation clicks. Test one video hook at a time with the same audience and spend. Set a baseline before judging lift; a reservation click is not a booked table.

Review & handoff

The existing video files passed decode checks and representative-frame inspection. Full-speed buyer approval is not established. A client engagement would first confirm venue assets, menu accuracy, reservation destination and required editable source format.
