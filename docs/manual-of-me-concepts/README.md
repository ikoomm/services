# Manual of Me — three independent concept studies

Interactive design samples by KOOM / Hazim Alsalmi. These are proposed directions for design discussion, not a delivered client product or approved brand identity.

- `editorial.html`: continuous personal manual with nearby evidence.
- `guided.html`: one report chapter at a time.
- `action.html`: a seven-day journal with browser-local sample checkmarks.
- `manual.pdf`: eight-page sample report and source answers.

All participant answers and report content are fictional. `report-data.json` is the shared content source. Observations, hypotheses, suggestions and unknowns are labelled separately. No live assessment, AI request, analytics, CRM integration or appointment booking is performed. Journal marks are saved only in the visitor's browser and can be reset.

Serve this folder over HTTP to load the shared JSON. The existing portfolio supplies self-hosted DM Sans and Newsreader fonts in `../studio/assets/`; their source and OFL licence records are in that asset folder. Preview images are captures of these original sample pages. No client photos, logos, private records or copied report assets are included.
